# WizTalk v1.0.0 Release

## Release Information

**Version:** v1.0.0

**Release Date:** 2026-09-01

## Release Summary

WizTalk v1.0.0 is the first stable architectural release.

This release establishes the foundation for an extensible Persian-first AI conversational platform.
