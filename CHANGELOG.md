# Changelog

All notable changes to the WizTalk project are documented in this file.

The format is based on Keep a Changelog and this project follows Semantic Versioning.

---

## [1.0.0] - 2026-09-01

### Added

- WizTalk V1 architecture foundation.
- Configurable AI character system.
- Character management capabilities.
- AI provider abstraction layer.
- Server-side AI provider integration.
- Avatar architecture foundation.
- Voice service architecture foundation.
- Memory service abstraction.
- GitHub Actions CI workflow.
- Deployment preparation support.

### Changed

- Refactored application structure into UI, domain, and service layers.
- Improved backend organization.
- Improved environment-based configuration.
- Improved character and AI service extensibility.

### Security

- Removed client-side API key storage approach.
- Moved provider credentials to server-side environment configuration.
- Improved separation between frontend and backend responsibilities.

### Infrastructure

- Added CI validation workflow.
- Added production build verification.
- Improved deployment readiness.

---

## [0.1.0]

### Added

- Initial WizTalk application.
- React frontend.
- AI chatbot interface.
- Persian conversational support.
- Character-based experience.

---

## Versioning

WizTalk follows Semantic Versioning:

- MAJOR: Breaking architectural or API changes.
- MINOR: New backward-compatible features.
- PATCH: Bug fixes and improvements.
